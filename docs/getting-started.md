# Erste Schritte – in 10 Minuten zum Lebenslauf

## 1. Start-Auswahl

Nach dem Start fragt die App:

- **Leeren Lebenslauf erstellen** – frisch anfangen (Profil, Erfahrung,
  Ausbildung, Kenntnisse, Sprachen sind schon angelegt)
- **Beispiel-Lebenslauf laden** – fiktiver Max Mustermann zum Ausprobieren
  (empfohlen für den Anfang)
- **Bestehendes Projekt öffnen** – eine früher gespeicherte `.json`-Datei

## 2. Die drei Bereiche

- **Links (Sidebar):** oben die *Vorlage* wählen, darunter die *Abschnitte*.
  Die Reihenfolge dort ist exakt die Reihenfolge im PDF.
- **Mitte (Editor):** Abschnitt anklicken → Formular erscheint.
  Jede Eingabe aktualisiert sofort die Vorschau (kleine Verzögerung normal).
- **Rechts (Vorschau):** A4-Seiten wie im späteren PDF. Unten blättern
  (*Seite 1 / 2*), rechts zoomen (`−` / `%` / `+` / *Einpassen*).

## 3. Persönliche Daten + Foto

1. Links **Persönliche Daten** wählen.
2. Name, Titel, Adresse, Telefon, E-Mail, Links eintragen.
3. **Foto auswählen** → JPG/PNG wählen (quadratisch wirkt am besten).
   Ohne Foto bleibt das Layout intakt. Mit **Foto entfernen** löschbar.
4. Der volle Name wird automatisch aus Vor- + Nachname gebildet.

## 4. Abschnitte bearbeiten

- **Profil:** 3–5 Sätze, konkret mit Zahlen (Zähler hilft).
- **Berufserfahrung / Ausbildung / …:** `+ Hinzufügen` → Dialog ausfüllen →
  *OK*. Doppelklick bearbeitet, **Entf**-Taste löscht (mit Rückfrage).
  Aktuellste Position zuerst (Reihenfolge per Liste oder Sidebar ändern).
- **Kenntnisse:** Name + Kategorie (z. B. *Programmiersprachen*). Im Feld
  *Level* optional eine Prozentzahl (`80 %`) → Terminal-Stil zeigt Balken.
- **Sprachen:** Niveau nach CEFR (A1–C2, Muttersprache).
- **Zertifikate:** optional **Scan anhängen** (JPG/PNG/PDF) – wird ans
  Export-PDF angehängt (siehe [PDF-Export](export.md)).
- **Interessen:** eine Zeile pro Interesse.

## 5. Abschnitte verwalten (Sidebar)

| Aktion | Wie |
|---|---|
| Reihenfolge ändern | Eintrag mit der Maus an neue Stelle ziehen **oder** ↑/↓-Buttons |
| Hinzufügen | **+ Abschnitt hinzufügen** → Typ wählen (Doppelte sind gesperrt, eigene beliebig) |
| Eigener Abschnitt | Als Typ *Eigener Abschnitt* → freien Titel vergeben (z. B. „Verfügbarkeit“) |
| Duplizieren | Nur eigene Abschnitte (Button oder Rechtsklick-Menü) |
| Löschen | Button, Rechtsklick oder **Entf**-Taste (mit Rückfrage) |
| Anschreiben | Fester Eintrag **Anschreiben** (nicht verschiebbar) → siehe [Anschreiben](cover-letter.md) |

Graue Einträge sind noch leer und erscheinen **nicht** im PDF.

## 6. Vorlage & Design

- Vorlage oben in der Sidebar wechseln (13 Stile, siehe [Vorlagen](templates.md)).
- **🎨 Design-Einstellungen:** Akzentfarbe, Hintergrundfarbe, Schriftart
  (10 Schriften), Größen, Abstände, Seitenränder, Kontakt-Kürzel,
  Zertifikats-Anhang an/aus.
- App-Farbschema (hell/dunkel) unter Menü *Ansicht* – unabhängig vom PDF.

## 7. Speichern & Exportieren

- **Datei → Speichern**: Projekt als `.json` sichern (am besten nach jedem
  größeren Block). Ungespeicherte Änderungen zeigt ein `*` im Fenstertitel.
- **Datei → Bewerbung exportieren**: komplettes PDF (Anschreiben, falls
  aktiv + Lebenslauf + Zertifikats-Scans). Details: [PDF-Export](export.md).
